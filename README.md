# keystone-field-service-platform
Field Service Management Platform built with Spring Boot, Spring Security, PostgreSQL, Flyway, and React.
A full-stack Field Service Management Platform designed to
manage customers, service locations, work orders, technician
assignments, inventory usage, time tracking, and SLA monitoring.

## Tech Stack

- Java 21
- Spring Boot 3
- Spring Security
- Spring Data JPA
- PostgreSQL
- Flyway
- Maven
- React and TypeScript (planned)

## Architecture

The backend follows a layered architecture:

- Controllers
- Services
- Repositories
- Domain models
- DTOs
- Security
- Exception handling
